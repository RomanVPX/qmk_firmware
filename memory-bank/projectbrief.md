# Проект: Улучшение подсветки клавиатуры Keychron K13 Max

## Обзор проекта
Проект направлен на улучшение функциональности RGB-подсветки клавиатуры Keychron K13 Max (ANSI, RGB) с прошивкой QMK/VIA. Основная цель - сделать подсветку более функциональной и информативной, чтобы она отражала текущее состояние клавиатуры и активные слои.

## Основные задачи
1. **Индикация клавиш при переключении слоев** - Реализовано: подсветка клавиш, которые меняют своё назначение при активации дополнительного слоя.

2. **F-Layer для функциональных клавиш** - Текущая задача: создание дополнительного слоя, в котором клавиши F1-F12 будут выполнять свою прямую функцию, а не macOS-функции.
   - Активация/деактивация через комбинацию [MO+l]
   - Подсветка F1-F12 при активном F-слое
   - Изменение цвета подсветки F1-F12 при использовании M0 с активным F-слоем

## Технические требования
- Использование существующей архитектуры QMK
- Минимальное влияние на производительность
- Интуитивно понятная индикация состояния клавиатуры через подсветку

## Ограничения
- Ограниченное количество слоев в QMK
- Необходимость сохранения совместимости с существующими функциями клавиатуры
