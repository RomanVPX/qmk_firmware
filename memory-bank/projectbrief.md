# Проектное задание: F-Layer для Keychron K13 Max

## Основные требования

### Цель проекта
Реализовать F-Layer для клавиатуры Keychron K13 Max, который позволит использовать клавиши F1-F12 в их прямом назначении без необходимости постоянно удерживать клавишу Fn.

### Функциональные требования
1. **Активация/деактивация F-Layer**: F-Layer должен активироваться/деактивироваться при нажатии комбинации [MO+l] (Fn+l)
2. **Прямое использование F-клавиш**: При активном F-Layer клавиши F1-F12 должны выполнять свою прямую функцию, а не macOS-функции
3. **Визуальная индикация**: При активном F-Layer клавиши F1-F12 должны быть подсвечены для индикации их состояния
4. **Взаимодействие с MAC_FN**: При использовании MAC_FN с активным F-Layer, клавиши F1-F12 должны иметь особое поведение и индикацию

### Технические требования
1. **Совместимость с QMK**: Реализация должна быть совместима с фреймворком QMK
2. **Минимальное влияние на существующую функциональность**: Реализация не должна нарушать существующую функциональность клавиатуры
3. **Эффективное использование ресурсов**: Реализация должна эффективно использовать доступные ресурсы QMK

## Контекст проекта

### Исходная ситуация
Клавиатура Keychron K13 Max использует фреймворк QMK и имеет RGB-подсветку. По умолчанию, в macOS клавиши верхнего ряда выполняют macOS-функции (яркость, громкость и т.д.), а для использования F1-F12 необходимо удерживать клавишу Fn.

### Проблема
Иногда клавиши F1-F12 нужны на длительное время, и использовать их постоянно в сочетании с Fn не слишком удобно.

### Решение
Реализовать F-Layer, который позволит использовать клавиши F1-F12 в их прямом назначении без необходимости постоянно удерживать клавишу Fn. F-Layer будет активироваться/деактивироваться при нажатии комбинации [MO+l] (Fn+l).

## Ограничения и допущения

### Ограничения
- Ограниченное количество слоев в QMK
- Ограниченные ресурсы микроконтроллера
- Необходимость сохранения совместимости с существующей функциональностью

### Допущения
- Пользователь знаком с базовой функциональностью клавиатуры Keychron K13 Max
- Пользователь использует macOS в качестве основной операционной системы
- Пользователь знаком с концепцией слоев в QMK

## Критерии успеха

### Функциональные критерии
1. F-Layer активируется/деактивируется при нажатии комбинации [MO+l] (Fn+l)
2. При активном F-Layer клавиши F1-F12 выполняют свою прямую функцию
3. При активном F-Layer клавиши F1-F12 подсвечены для индикации их состояния
4. При использовании MAC_FN с активным F-Layer, клавиши F1-F12 имеют особое поведение и индикацию

### Технические критерии
1. Реализация совместима с фреймворком QMK
2. Реализация не нарушает существующую функциональность клавиатуры
3. Реализация эффективно использует доступные ресурсы QMK
