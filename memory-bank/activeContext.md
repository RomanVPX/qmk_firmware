# Активный контекст: Реализация F-Layer

## Текущий фокус работы
Реализация F-Layer для клавиатуры Keychron K13 Max, который позволит использовать клавиши F1-F12 в их прямом назначении без необходимости постоянно удерживать клавишу Fn.

## Недавние изменения
- Анализ существующего кода клавиатуры Keychron K13 Max
- Изучение документации QMK по работе со слоями и RGB-подсветкой
- Разработка подхода к реализации F-Layer без использования дополнительного слоя в стеке QMK

## Следующие шаги
1. Добавление нового кейкода `TOGGLE_F_LAYER` в перечисление `custom_keycodes`
2. Добавление переменной для отслеживания состояния F-Layer
3. Модификация функции `process_record_user()` для обработки нового кейкода и изменения поведения F-клавиш
4. Расширение функции `rgb_matrix_indicators_advanced_user()` для визуальной индикации состояния F-Layer
5. Тестирование и отладка реализации

## Активные решения и соображения

### Подход к реализации F-Layer
Вместо создания отдельного слоя в стеке слоев QMK, мы используем логическую переменную для отслеживания состояния F-Layer. Это решение было выбрано, чтобы:
- Сохранить ограниченные ресурсы слоев
- Упростить логику переключения
- Избежать конфликтов с существующими слоями

### Визуальная индикация
Для визуальной индикации состояния F-Layer мы используем следующие цвета:
- RGB_CYAN для F-клавиш при активном F-Layer
- RGB_RED для F-клавиш при комбинации F-Layer + MAC_FN

### Активация F-Layer
F-Layer будет активироваться/деактивироваться при нажатии комбинации [MO+l], где:
- MO - клавиша Fn, активирующая слой MAC_FN
- l - клавиша 'l' на слое MAC_FN

## Важные паттерны и предпочтения

### Паттерны кода
- Использование логической переменной для отслеживания состояния
- Перехват и модификация поведения клавиш в `process_record_user()`
- Визуальная индикация через `rgb_matrix_indicators_advanced_user()`

### Предпочтения по стилю кода
- Следование стилю существующего кода
- Использование комментариев для объяснения логики
- Минимальное вмешательство в существующий код

## Полученные знания и инсайты
- QMK предоставляет гибкие возможности для кастомизации поведения клавиатуры
- RGB-подсветка может использоваться не только для декоративных целей, но и для функциональной индикации
- Реализация дополнительной функциональности не всегда требует создания новых слоев
