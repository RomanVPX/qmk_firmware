# Контекст продукта: Улучшение подсветки Keychron K13 Max

## Проблема
Стандартная подсветка на клавиатурах с QMK/VIA прошивкой, включая Keychron K13 Max, имеет преимущественно декоративную функцию. Единственная полезная информация, которую она предоставляет - это уровень заряда аккумулятора. Это значительно ограничивает потенциал RGB-подсветки как инструмента для улучшения пользовательского опыта.

## Решение
Реализация интеллектуальной подсветки, которая:
1. Визуально отображает изменения в функциональности клавиш при переключении слоев
2. Предоставляет визуальную обратную связь о текущем состоянии клавиатуры
3. Помогает пользователю быстрее адаптироваться к сложным раскладкам с несколькими слоями

## Пользовательский опыт
### Текущий опыт
- Пользователь должен помнить, какие клавиши меняют своё назначение при активации различных слоев
- При работе с macOS функциональные клавиши F1-F12 по умолчанию выполняют системные функции, а не свою прямую функцию
- Для использования F1-F12 в их прямом назначении требуется постоянно удерживать клавишу Fn (MO)

### Целевой опыт
- Пользователь видит, какие клавиши изменят своё назначение при активации слоя
- Пользователь может активировать F-Layer для длительного использования F1-F12 без необходимости постоянно удерживать Fn
- Цветовая индикация помогает понять текущее состояние клавиатуры и активные слои

## Ценность для пользователя
- Повышение эффективности работы с клавиатурой
- Снижение когнитивной нагрузки при использовании сложных раскладок
- Более интуитивное взаимодействие с функциональными клавишами
- Возможность настройки клавиатуры под специфические рабочие процессы
