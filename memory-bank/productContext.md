# Продуктовый контекст: F-Layer для Keychron K13 Max

## Почему этот проект существует

### Проблема пользователя
Клавиатура Keychron K13 Max в режиме macOS использует клавиши верхнего ряда для управления системными функциями (яркость экрана, громкость и т.д.). Для доступа к функциональным клавишам F1-F12 необходимо удерживать клавишу Fn. Это создает неудобство в ситуациях, когда функциональные клавиши нужны на длительное время, например:
- При работе в IDE, где F-клавиши используются для отладки (F5, F9, F10, F11)
- При работе в графических редакторах, где F-клавиши используются для переключения инструментов
- При работе в играх, где F-клавиши используются для различных действий

### Решаемая задача
F-Layer решает проблему постоянного удержания клавиши Fn для доступа к функциональным клавишам F1-F12. Он позволяет переключаться между режимами, где клавиши верхнего ряда работают как:
1. Системные функции macOS (яркость, громкость и т.д.) - стандартный режим
2. Функциональные клавиши F1-F12 - режим F-Layer

## Как это должно работать

### Пользовательский сценарий
1. Пользователь нажимает комбинацию [Fn+l] для активации F-Layer
2. Клавиши F1-F12 подсвечиваются бирюзовым цветом, указывая на их новое назначение
3. Пользователь использует клавиши F1-F12 напрямую, без необходимости удерживать Fn
4. При необходимости использовать системные функции macOS, пользователь может нажать Fn, при этом клавиши F1-F12 подсветятся красным цветом
5. Для возврата к стандартному режиму пользователь снова нажимает комбинацию [Fn+l]

### Интерфейс пользователя
Интерфейс пользователя реализован через RGB-подсветку клавиш:
- Бирюзовый цвет (RGB_CYAN) для F-клавиш при активном F-Layer
- Красный цвет (RGB_RED) для F-клавиш при комбинации F-Layer + MAC_FN
- Отсутствие специальной подсветки в стандартном режиме

## Цели пользовательского опыта

### Удобство использования
F-Layer должен обеспечивать удобный доступ к функциональным клавишам F1-F12 без необходимости постоянно удерживать клавишу Fn. Переключение между режимами должно быть интуитивно понятным и быстрым.

### Визуальная обратная связь
F-Layer должен обеспечивать четкую визуальную обратную связь о текущем режиме работы клавиш F1-F12 через RGB-подсветку. Это позволит пользователю легко определить, в каком режиме находятся клавиши.

### Совместимость с существующими функциями
F-Layer должен быть совместим с существующими функциями клавиатуры Keychron K13 Max, включая переключение между слоями MAC_BASE, MAC_FN, WIN_BASE, WIN_FN и использование пользовательских макросов.

## Ключевые особенности и преимущества

### Ключевые особенности
1. **Переключаемый режим F-клавиш**: Возможность переключаться между режимами, где клавиши верхнего ряда работают как системные функции macOS или как функциональные клавиши F1-F12
2. **Визуальная индикация**: Четкая визуальная индикация текущего режима работы клавиш F1-F12 через RGB-подсветку
3. **Интуитивное управление**: Простое и интуитивное управление режимами через комбинацию [Fn+l]
4. **Совместимость с существующими функциями**: Полная совместимость с существующими функциями клавиатуры Keychron K13 Max

### Преимущества для пользователя
1. **Повышение продуктивности**: Более удобный доступ к функциональным клавишам F1-F12 повышает продуктивность при работе в приложениях, где эти клавиши используются часто
2. **Снижение усталости**: Отсутствие необходимости постоянно удерживать клавишу Fn снижает усталость пальцев при длительной работе с F-клавишами
3. **Улучшение пользовательского опыта**: Визуальная индикация и интуитивное управление улучшают общий пользовательский опыт работы с клавиатурой
4. **Расширение функциональности**: F-Layer расширяет функциональность клавиатуры Keychron K13 Max, делая ее более гибкой и адаптируемой к различным задачам
