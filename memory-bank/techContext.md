# Технический контекст: F-Layer для Keychron K13 Max

## Используемые технологии

### QMK Firmware
QMK (Quantum Mechanical Keyboard) - это открытый фреймворк для программирования клавиатур. Он предоставляет широкие возможности для кастомизации поведения клавиатуры, включая:
- Определение раскладок и слоев
- Программирование макросов
- Управление RGB-подсветкой
- Обработка нажатий клавиш

Основные компоненты QMK, используемые в проекте:
- Система слоев для расширения функциональности клавиатуры
- Функции для обработки нажатий клавиш (`process_record_user()`)
- Функции для управления RGB-подсветкой (`rgb_matrix_indicators_advanced_user()`)
- Функции для активации/деактивации слоев (`layer_on()`, `layer_off()`)
- XOR-операции для инвертирования состояния слоя (`state ^ (1UL << layer)`)
- Функции проверки активности слоя (`layer_state_is()`, `IS_LAYER_ON_STATE()`)

### Keychron K13 Max
Keychron K13 Max - это механическая клавиатура с поддержкой QMK и RGB-подсветкой. Основные характеристики:
- 96% раскладка (ANSI)
- RGB-подсветка с поддержкой настройки для каждой клавиши
- Поддержка QMK и VIA
- Bluetooth и проводное подключение
- Поддержка macOS и Windows

## Настройка разработки

### Среда разработки
Для разработки используется:
- Visual Studio Code с расширениями для C/C++
- QMK CLI для компиляции и прошивки
- Git для контроля версий

### Процесс сборки
Процесс сборки прошивки включает:
1. Клонирование репозитория QMK от Keychron
2. Создание ветки для разработки
3. Настройка QMK CLI для сборки прошивки
4. Компиляция прошивки с помощью команды `qmk compile -kb keychron/k13_max/ansi/rgb -km RomanVPX`
5. Прошивка клавиатуры с помощью команды `qmk flash -kb keychron/k13_max/ansi/rgb -km RomanVPX`

## Технические ограничения

### Ограничения QMK
- Ограниченное количество слоев (32 слоя максимум, но рекомендуется использовать меньше)
- Ограниченные ресурсы микроконтроллера (память, процессорное время)
- Ограничения на количество и сложность макросов
- Приоритет get_highest_layer при нескольких активных слоях

### Ограничения Keychron K13 Max
- Фиксированная физическая раскладка (96% ANSI)
- Ограниченное количество RGB-светодиодов
- Ограничения на энергопотребление в беспроводном режиме

## Паттерны использования инструментов

### Работа со слоями в QMK
Для работы со слоями в QMK используются следующие паттерны:
- Определение слоев в перечислении `layers`
- Определение раскладок для каждого слоя в массиве `keymaps`
- Активация/деактивация слоев через функции `layer_on()`, `layer_off()`
- Проверка активности слоя через функцию `layer_state_is()`
- Инвертирование состояния слоя через XOR-операцию (`state ^ (1UL << layer)`)
- Использование коллбэка `layer_state_set_user()` для автоматического управления слоями

### Работа с RGB-подсветкой в QMK
Для работы с RGB-подсветкой в QMK используются следующие паттерны:
- Определение цветов через константы `RGB_*` или прямые значения RGB
- Установка цвета для конкретного светодиода через функцию `rgb_matrix_set_color()`
- Кастомизация подсветки через функцию `rgb_matrix_indicators_advanced_user()`
- Проверка активности слоя через `layer_state_is()` для корректной индикации при нескольких активных слоях

### Обработка нажатий клавиш в QMK
Для обработки нажатий клавиш в QMK используются следующие паттерны:
- Определение пользовательских кейкодов в перечислении `custom_keycodes`
- Обработка нажатий клавиш в функции `process_record_user()`
- Использование простых и понятных условных конструкций
- Предпочтение прямого переключения слоев вместо сложной логики с переменными состояния

## Особенности реализации

### Реализация F-Layer
F-Layer реализован через настоящий слой QMK (MAC_F_LAYER), который является прозрачным, кроме F1-F12. Основные компоненты реализации:
1. Добавлен слой MAC_F_LAYER в перечисление layers
2. Создана раскладка для MAC_F_LAYER (прозрачная, кроме F1-F12)
3. Реализовано автоматическое инвертирование MAC_F_LAYER при активации/деактивации MAC_FN через коллбэк layer_state_set_user()
4. Реализовано переключение MAC_F_LAYER через кейкод TOGGLE_F_LAYER и обработчик в process_record_user()
5. Настроена визуальная индикация состояния F-Layer через функцию rgb_matrix_indicators_advanced_user()

### Ключевые оптимизации
1. **Инвертирование слоя через XOR**: Использование XOR-операции для элегантного инвертирования состояния слоя
```c
state = state ^ (1UL << MAC_F_LAYER);
```

2. **Проверка активности слоя через layer_state_is()**: Использование функции layer_state_is() вместо проверки current_layer для корректной работы при нескольких активных слоях
```c
if (layer_state_is(MAC_F_LAYER)) {
    highlight_f_keys(led_min, led_max, 0, 255, 255);
}
```

3. **Упрощенный обработчик TOGGLE_F_LAYER**: Использование простой и понятной логики переключения слоя
```c
if (layer_state_is(MAC_F_LAYER)) {
    layer_off(MAC_F_LAYER);
} else {
    layer_on(MAC_F_LAYER);
}
```

4. **Выделение повторяющейся логики**: Использование функции highlight_f_keys() для выделения повторяющейся логики подсветки F-клавиш
```c
void highlight_f_keys(uint8_t led_min, uint8_t led_max, uint8_t r, uint8_t g, uint8_t b) {
    for (uint8_t row = 0; row < MATRIX_ROWS; ++row) {
        for (uint8_t col = 0; col < MATRIX_COLS; ++col) {
            uint16_t keycode = keymap_key_to_keycode(MAC_F_LAYER, (keypos_t){col, row});
            if (keycode >= KC_F1 && keycode <= KC_F12) {
                uint8_t index = g_led_config.matrix_co[row][col];
                if (index != NO_LED && index >= led_min && index < led_max) {
                    rgb_matrix_set_color(index, r, g, b);
                }
            }
        }
    }
}
```

### Визуальная индикация
Визуальная индикация реализована через бинарную концепцию:
- Бирюзовый цвет (RGB_CYAN) для F-клавиш при активном MAC_F_LAYER
- Отсутствие специальной подсветки для F-клавиш при неактивном MAC_F_LAYER
- Подсветка всех модифицированных клавиш в слое MAC_FN при его активации
