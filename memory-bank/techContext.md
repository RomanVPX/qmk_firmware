# Технический контекст: Реализация F-Layer в QMK

## Используемые технологии

### QMK Firmware
QMK (Quantum Mechanical Keyboard) - это открытый фреймворк для программирования клавиатур. Он предоставляет широкие возможности для кастомизации поведения клавиатуры, включая:
- Настройку раскладок и слоев
- Макросы и сложные комбинации клавиш
- Управление подсветкой
- Расширенные функции (tap dance, комбо и т.д.)

### RGB Matrix
Подсистема RGB Matrix в QMK предназначена для управления RGB-светодиодами на клавиатуре. Она поддерживает:
- Индивидуальное управление каждым светодиодом
- Различные эффекты подсветки
- Настройку цвета, яркости, насыщенности
- Кастомные индикаторы для отображения состояния клавиатуры

## Технические ограничения

### Ограничения QMK
- Ограниченное количество слоев (32 в текущей версии)
- Ограничения по памяти микроконтроллера
- Потенциальные конфликты между различными функциями

### Ограничения клавиатуры Keychron K13 Max
- Специфическая конфигурация светодиодов
- Особенности работы с Bluetooth и аккумулятором
- Совместимость с существующими функциями

## Технические решения

### Реализация F-Layer без использования дополнительного слоя
Вместо создания отдельного слоя в стеке слоев QMK, мы используем логическую переменную для отслеживания состояния F-Layer. Это позволяет:
- Сохранить ограниченные ресурсы слоев
- Упростить логику переключения
- Избежать конфликтов с существующими слоями

### Перехват и модификация поведения F-клавиш
В функции `process_record_user()` мы перехватываем нажатия F-клавиш и модифицируем их поведение в зависимости от состояния F-Layer:
```c
if (f_layer_active && keycode >= KC_F1 && keycode <= KC_F12) {
    // Изменяем поведение F-клавиш
}
```

### Визуальная индикация через RGB Matrix
Используем функцию `rgb_matrix_indicators_advanced_user()` для визуального отображения состояния F-Layer:
```c
if (f_layer_active) {
    // Подсвечиваем F-клавиши соответствующим цветом
}
```
