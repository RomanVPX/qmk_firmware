# Системные паттерны: Архитектура подсветки в QMK

## Архитектура QMK для RGB-подсветки

### Слои в QMK
QMK использует систему слоев для расширения функциональности клавиатуры. Слои работают как "стопка", где активные слои накладываются друг на друга, и система ищет назначение клавиши, начиная с верхнего слоя и спускаясь вниз.

Основные компоненты работы со слоями:
- `layer_state` - битовая маска, отражающая текущее состояние слоев
- `default_layer_state` - битовая маска, указывающая на базовый слой
- Функции активации/деактивации слоев: `layer_on()`, `layer_off()`, `layer_invert()`
- Кейкоды для работы со слоями: `MO()`, `TG()`, `TO()`, `TT()`

### RGB Matrix в QMK
RGB Matrix - это подсистема QMK для управления RGB-светодиодами. Она предоставляет:
- Управление отдельными светодиодами
- Эффекты подсветки
- Функции для установки цвета, яркости и других параметров
- Колбэки для кастомизации подсветки

Ключевые компоненты:
- `g_led_config` - конфигурация светодиодов (физическое расположение, связь с матрицей клавиш)
- `rgb_matrix_set_color()` - установка цвета для конкретного светодиода
- `rgb_matrix_indicators_advanced_user()` - колбэк для кастомной индикации

## Паттерны реализации F-Layer

### Паттерн "Состояние без слоя"
Вместо создания отдельного слоя для F-клавиш, мы используем логическую переменную для отслеживания состояния F-Layer. Это позволяет:
- Избежать использования дополнительного слоя в стеке слоев QMK
- Сохранить совместимость с существующими слоями
- Упростить логику переключения

### Паттерн "Перехват клавиш"
В функции `process_record_user()` мы перехватываем нажатия F-клавиш и изменяем их поведение в зависимости от состояния F-Layer:
- Если F-Layer активен, F-клавиши отправляют свои прямые коды
- Если F-Layer не активен, F-клавиши работают как обычно (системные функции macOS)

### Паттерн "Визуальная индикация состояния"
Используем функцию `rgb_matrix_indicators_advanced_user()` для визуального отображения состояния F-Layer:
- Подсветка F-клавиш цветом RGB_CYAN при активном F-Layer
- Изменение цвета на RGB_RED при комбинации F-Layer + MAC_FN

## Ключевые взаимодействия компонентов

```
┌─────────────────────┐      ┌─────────────────────┐
│  process_record_user │◄────►│  Состояние F-Layer  │
└─────────────────────┘      └─────────────────────┘
           ▲                            │
           │                            ▼
┌─────────────────────┐      ┌─────────────────────┐
│  Обработка клавиш    │      │  RGB-индикация      │
└─────────────────────┘      └─────────────────────┘
```

Этот подход обеспечивает:
- Минимальное влияние на существующую функциональность
- Интуитивно понятную индикацию состояния
- Гибкость в настройке поведения F-клавиш
