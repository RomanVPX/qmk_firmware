# Прогресс проекта

## Что работает
- Базовая функциональность клавиатуры Keychron K13 Max
- Переключение между слоями MAC_BASE, MAC_FN, WIN_BASE, WIN_FN
- Пользовательские макросы (MACRO0-MACRO15)
- RGB-подсветка и индикация активных слоев
- F-Layer для использования клавиш F1-F12 в их прямом назначении (реализовано через слой MAC_F_LAYER)
- Автоматическое инвертирование MAC_F_LAYER при активации/деактивации MAC_FN
- Визуальная индикация F-клавиш и клавиш MAC_FN при активных слоях
- Корректная подсветка при нескольких активных слоях одновременно
- Автоматическое отключение MAC_F_LAYER при переключении в режим Windows (через физический переключатель или слои)

## Что осталось реализовать
- Аналогичная функциональность для режима Windows (опционально)
- Возможные улучшения и расширения функциональности в будущем

## Текущий статус
Полностью реализован и оптимизирован F-Layer для клавиатуры Keychron K13 Max с элегантной логикой переключения слоев и индикацией. Проведено тестирование и отладка на реальной клавиатуре, все выявленные проблемы успешно решены.

### Основные компоненты реализации
1. Добавлен слой MAC_F_LAYER в перечисление layers
2. Создана раскладка для MAC_F_LAYER (прозрачная, кроме F1-F12, которые назначены на функциональные клавиши)
3. Реализовано переключение MAC_F_LAYER через кейкод TOGGLE_F_LAYER
4. Добавлен оптимизированный коллбэк layer_state_set_user() для автоматического инвертирования MAC_F_LAYER при активации/деактивации MAC_FN
5. Реализована функция highlight_f_keys() для подсветки F-клавиш
6. Оптимизирована функция rgb_matrix_indicators_advanced_user() для корректной подсветки клавиш при нескольких активных слоях

### Решенные проблемы
1. **Упрощена логика управления слоями**: Заменена сложная логика с дополнительной переменной на элегантное инвертирование слоя MAC_F_LAYER при активации/деактивации MAC_FN.
2. **Исправлена подсветка клавиш MAC_FN**: Заменена проверка `current_layer == MAC_FN` на `layer_state_is(MAC_FN)` для корректной подсветки при нескольких активных слоях.
3. **Упрощена визуальная индикация**: Убрана избыточная красная подсветка, введена простая бинарная концепция: подсветка есть = F-клавиши, подсветки нет = мультимедийные клавиши.
4. **Оптимизирован размер прошивки**: После внесенных изменений размер прошивки уменьшился с 65918 до 65774 байт.
5. **Реализовано надежное отключение MAC_F_LAYER**: Добавлена проверка и отключение MAC_F_LAYER в dip_switch_update_kb для мгновенного отключения при переключении в режим Windows.

## Эволюция проектных решений

### Первоначальный подход
Изначально F-Layer был реализован через логическую переменную `f_layer_active`, которая отслеживала состояние F-Layer. При активном F-Layer клавиши F1-F12 перехватывались в функции `process_record_user()` и отправляли свои прямые коды вместо кодов macOS-функций.

### Второй подход
Второй подход использовал настоящий слой QMK (MAC_F_LAYER), который был копией MAC_BASE, но с F1-F12 вместо медиа-клавиш. Это позволило использовать встроенные механизмы QMK для работы со слоями, но вызвало проблемы с деактивацией F-Layer и конфликты с MAC_FN.

### Третий подход
Третий подход сочетал использование настоящего слоя QMK (MAC_F_LAYER) с динамическим управлением слоями через коллбэк layer_state_set_user() и переменную f_layer_was_active. MAC_F_LAYER стал прозрачным слоем, кроме F1-F12, что решило проблему с деактивацией. Была реализована логика временного отключения MAC_F_LAYER при активации MAC_FN с сохранением его состояния.

### Текущий подход (оптимизированный)
Текущая реализация максимально упрощает логику переключения слоев за счет использования XOR-инвертирования и двухуровневой защиты:
- Убрана переменная f_layer_was_active и связанная с ней сложная логика
- MAC_F_LAYER автоматически инвертируется при активации/деактивации MAC_FN
- Упрощена логика подсветки, заменена проверка `current_layer == MAC_FN` на `layer_state_is(MAC_FN)`
- Убрана избыточная красная подсветка, введена бинарная концепция индикации
- Упрощен обработчик TOGGLE_F_LAYER для более предсказуемого поведения
- Реализована двойная защита от активного MAC_F_LAYER в режиме Windows:
  - Через dip_switch_update_kb при физическом переключении
  - Через layer_state_set_user при программном переключении слоев

## Известные проблемы
