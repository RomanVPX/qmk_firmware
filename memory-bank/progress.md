# Прогресс проекта

## Что работает
- Базовая функциональность клавиатуры Keychron K13 Max
- Переключение между слоями MAC_BASE, MAC_FN, WIN_BASE, WIN_FN
- Пользовательские макросы (MACRO0-MACRO15)
- RGB-подсветка и индикация активных слоев
- F-Layer для использования клавиш F1-F12 в их прямом назначении (реализовано через слой MAC_F_LAYER)
- Автоматическое переключение между MAC_F_LAYER и MAC_FN с сохранением состояния
- Визуальная индикация F-клавиш различными цветами в зависимости от состояния

## Что осталось реализовать
- Возможные улучшения и расширения функциональности в будущем

## Текущий статус
Реализован F-Layer для клавиатуры Keychron K13 Max с усовершенствованной логикой переключения слоев и индикацией. Проведено тестирование и отладка на реальной клавиатуре, выявленные проблемы успешно решены.

### Основные компоненты реализации
1. Добавлен новый слой MAC_F_LAYER в перечисление layers
2. Создана раскладка для MAC_F_LAYER (прозрачная, кроме F1-F12, которые назначены на функциональные клавиши)
3. Реализовано переключение на MAC_F_LAYER через кейкод TOGGLE_F_LAYER
4. Добавлен коллбэк layer_state_set_user() для автоматического управления состоянием слоев
5. Реализована функция highlight_f_keys() для удобной индикации состояния F-клавиш
6. Настроена визуальная индикация состояния F-Layer через RGB-подсветку

### Решенные проблемы
1. **Деактивация F-Layer**: Решена проблема с деактивацией слоя путем замены всех клавиш, кроме F1-F12, в MAC_F_LAYER на прозрачные.
2. **Конфликт с MAC_FN**: Реализовано временное отключение MAC_F_LAYER при активации MAC_FN с сохранением его состояния.
3. **Визуальная индикация**: Добавлена корректная индикация F-клавиш красным цветом при комбинации MAC_F_LAYER + MAC_FN.

## Эволюция проектных решений

### Первоначальный подход
Изначально F-Layer был реализован через логическую переменную `f_layer_active`, которая отслеживала состояние F-Layer. При активном F-Layer клавиши F1-F12 перехватывались в функции `process_record_user()` и отправляли свои прямые коды вместо кодов macOS-функций.

### Второй подход
Второй подход использовал настоящий слой QMK (MAC_F_LAYER), который был копией MAC_BASE, но с F1-F12 вместо медиа-клавиш. Это позволило использовать встроенные механизмы QMK для работы со слоями, но вызвало проблемы с деактивацией F-Layer и конфликты с MAC_FN.

### Текущий подход
Текущая реализация сочетает использование настоящего слоя QMK (MAC_F_LAYER) с динамическим управлением слоями через коллбэк layer_state_set_user(). Основные улучшения:
- MAC_F_LAYER теперь прозрачен, кроме F1-F12, что решает проблему с деактивацией
- Автоматическое отключение MAC_F_LAYER при активации MAC_FN с восстановлением при деактивации
- Улучшенная визуальная индикация состояния F-клавиш

## Известные проблемы
- Ошибки компиляции, связанные с опциями компилятора, не влияют на функциональность кода и могут быть игнорированы
