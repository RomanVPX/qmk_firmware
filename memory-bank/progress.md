# Прогресс проекта: Улучшение подсветки Keychron K13 Max

## Что работает
- **Базовая функциональность клавиатуры** - Стандартная раскладка и слои (MAC_BASE, MAC_FN, WIN_BASE, WIN_FN) работают корректно.
- **Индикация клавиш при переключении слоев** - Реализована подсветка клавиш, которые меняют своё назначение при активации дополнительного слоя.
- **Пользовательские макросы** - Реализованы различные макросы для специальных функций.

- **F-Layer для функциональных клавиш** - Текущая задача: создание дополнительного слоя, в котором клавиши F1-F12 будут выполнять свою прямую функцию.

## Текущий статус
В процессе реализации F-Layer. Разработан подход к реализации без использования дополнительного слоя в стеке QMK. Подготовлена документация и план реализации.

## Эволюция решений

### Индикация клавиш при переключении слоев
Первоначально была реализована функция `rgb_matrix_indicators_advanced_user()`, которая подсвечивает клавиши, меняющие своё назначение при активации дополнительного слоя. Эта функция использует метод `is_key_modified_in_layer()` для определения, изменяется ли функция клавиши при переключении слоя.

### F-Layer для функциональных клавиш
Рассмотрены два подхода к реализации:
1. **Создание отдельного слоя в стеке QMK** - Этот подход был отклонен из-за потенциальных конфликтов с существующими слоями и усложнения логики переключения.
2. **Использование логической переменной для отслеживания состояния** - Выбран этот подход как более простой и эффективный. Он позволяет избежать использования дополнительного слоя и упрощает логику переключения.
