# Информация о проекте

## Общие сведения
- Этот проект — форк форка репозитория QMK от Keychron и создан для создания кастомизированной прошивки для QMK-совместимой клавиатуры пользователя — Keychron K13 Max.
- Точка входа — `keyboards/keychron/k13_max/ansi/rgb/keymaps/RomanVPX/keymap.c`

## Технический контекст и особенности кодовой базы
- Для Keychron K13 Max нет прямой поддержки в репозитории QMK.
- В форке репозитория QMK от Keychron тоже не всё прямо хорошо с исходниками: у этой клавиатуры есть радиомодули Bluetooth и 2.4Ггц, поддержка которых есть только в ветках `wireless_playground` форка Keychron.
- Код в этих ветках несовместим с конфигураторами VIA, но этого и не требуется.
- Также в этих ветках довольно старая версия QMK и тут может не быть некоторых фичей из текущего репозитория QMK.
- Для облегчения работы, из проекта была удалена большая часть кода, не имеющая отношения непосредственно к Keychron K13 Max.

## Документация
- В проекте есть полная документация для этой версии кода.
- Так как форк сильно расходится с актуальным репозиторием QMK, в случае сомнений лучше обращаться к локальной документации.
- Вся документация находится в директории `docs` в корне проекта.
